Add or update your team's listing

Each team on this site is one file in our GitHub repository. You add or update a listing by proposing a change to that file. An RSSN reviewer checks it, and it goes live a minute or two after it's approved.

You'll need a free GitHub account. You don't need to install anything.

Add a new listing

  1. Click Copy the template, then Start a new listing on GitHub. GitHub opens a new, empty file.
  2. Paste the template into the file, and change the file name at the top to your team's name in lowercase with hyphens, like imaging-software-team.md.
  3. Fill in each field. The fields follow the RSSN Research IT Provider Questionnaire. For lists, delete the lines that don't apply and keep the spelling of the rest exactly as written. For single answers, pick one of the values in the comment above the field. Anything that doesn't fit goes in the matching _other field.
  4. Replace the last paragraph with a 2–3 sentence description of your team.
  5. Click Commit changes, then Propose changes, then Create pull request.

Start a new listing on GitHub

Already filled out the questionnaire?

You don't need to do anything else. RSSN imports questionnaire responses into listings and will ask you to review yours before it goes live.

Update an existing listing

Open your team's profile on this site and click Suggest an edit on GitHub at the bottom. Make your changes, then propose them the same way.
