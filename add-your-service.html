Add or update your team's listing

Each team on this site is one file in our GitHub repository. You add or update a listing by proposing a change to that file. An RSSN reviewer checks it, and it goes live a minute or two after it's approved.

You'll need a free GitHub account. You don't need to install anything.

Add a new listing

  1. Click Start a new listing below. GitHub opens a new file that's already filled in with the listing template.
  2. Change the file name at the top to your team's name in lowercase with hyphens, like imaging-software-team.md.
  3. Fill in each field. For the lists (who can engage you, services), delete the lines that don't apply. Keep the spelling of the ones you keep exactly as written.
  4. Replace the last paragraph with a 2–3 sentence description of your team.
  5. Click Commit changes, then Propose changes, then Create pull request.

Update an existing listing

Open your team's profile on this site and click Suggest an edit on GitHub at the bottom. Make your changes, then propose them the same way.
