Add or update your team's listing

Each team on this site is one file in our GitHub repository. You add or update a listing by proposing a change to that file. An RSSN reviewer checks it, and it goes live a minute or two after it's approved.

You'll need a free GitHub account. You don't need to install anything.

Add a new listing

  1. Click Copy the template, then Start a new listing on GitHub. GitHub opens a new, empty file.
  2. Paste the template into the file, and change the file name at the top to your team's name in lowercase with hyphens, like imaging-software-team.md.
  3. Fill in each field. The fields follow the RSSN Research IT Provider Questionnaire, and every answer choice is already in the file. A line that starts with #  isn't selected: delete the #  to select it. Questions marked CHOOSE ONE should have exactly one line selected; CHOOSE ALL THAT APPLY questions can have any number. After each service, write not offered, offered, or strength (no more than five strengths). Anything that doesn't fit goes in the matching _other line.
  4. Replace the text at the bottom with an optional short paragraph about your team (about 500 characters), or delete it. The site builds your card's summary from your answers, so there's no need to repeat them.
  5. Click Commit changes, then Propose changes, then Create pull request.

Already filled out the questionnaire?

You don't need to do anything else. RSSN imports questionnaire responses into listings and will ask you to review yours before it goes live. After that, please make changes on GitHub as described below rather than resubmitting the questionnaire.

Update an existing listing

Open your team's profile on this site and click Suggest an edit on GitHub at the bottom. Every answer choice is listed in the file, so you only need to select or unselect lines: delete the #  in front of an answer to select it, or type #  in front of it to unselect it. To change a service, change the word after it to not offered, offered, or strength. Update the updated: date, then propose your changes the same way.
